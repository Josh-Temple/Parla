# Card Dataset Quality Checklist

Use this checklist when adding or editing AI-survival cards.

- One card = one clear communicative purpose.
- `support.jaHint` must be a direct Japanese recall cue (not a meta note).
- `pattern` must be reusable with replaceable slots.
- `example` must be short, realistic, and spoken/written in real practice.
- `quick_variations` must be specific to the card (no generic duplicates).
- `notes` should explain **when** to use the phrase.
- `contrast` should explain the difference from a nearby phrase.
- `practice_note` should tell the learner exactly how to drill the phrase.
- `ai_transfer_prompt` should describe when to use it with an external AI partner.
- `prompts.intent` + `prompts.situation` should make front-side recall possible before reveal.
