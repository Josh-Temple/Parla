# Voice Survival User Validation Plan

## Goal and hypothesis

Test whether Japanese learners of English can practice phrases in Parla, start an English conversation with an external AI, and use a practiced phrase to keep the conversation going when it becomes difficult.

The first test uses the existing **Voice Survival** Practice Set. Test with **3–5 people** before considering major new features.

## Participants

- Adult learners of English whose first language is Japanese
- People who can use an AI chat or voice-conversation tool
- 3–5 participants for the first round

## Test setup

- Ask the participant to use their own phone when possible.
- Confirm that an external tool such as ChatGPT, Gemini, or Claude is available before starting.
- Do not explain Parla's flow unless the participant cannot continue. Record any help that you give.
- Ask for permission before recording the screen, audio, or identifiable notes.

## Tasks

1. Open the Parla home page.
2. Start **Voice Survival**.
3. Complete the Practice Set.
4. Copy the conversation prompt.
5. Use the prompt to start a conversation in ChatGPT, Gemini, Claude, or another external AI.
6. Use a Parla phrase when it is needed during the conversation. The participant does not need to use all six phrases.

## Observe

- Could the participant start without an explanation?
- Did the participant complete the Practice Set?
- Could the participant copy the prompt?
- Did the participant actually start a conversation with an external AI?
- Did the participant use at least one practiced phrase?
- On which screen or wording did the participant hesitate or become confused?
- Would the participant want to use Parla again within the next few days?

Record task completion, notable behavior, and the participant's words separately. Avoid teaching or correcting during the task.

## Questions after the test

1. **What did you think Parla was for?**  
   Parlaは何のためのものだと思いましたか？
2. **Where did you hesitate or feel confused?**  
   どこで迷ったり、分かりにくいと感じたりしましたか？
3. **Did the practice help during the AI conversation?**  
   練習はAIとの会話で役に立ちましたか？
4. **Which phrase was most useful?**  
   どのフレーズが最も役に立ちましたか？
5. **Would you use this again without being reminded?**  
   誰かに促されなくても、もう一度使いたいですか？
6. **What is the one thing you would change?**  
   一つだけ変えるとしたら、何を変えますか？

## Decision after the first round

Continue improving this flow—not expanding the product—until at least three participants complete **Practice Set → copy prompt → external AI conversation**. Review where participants stopped, whether at least one practiced phrase transferred into conversation, and whether they would return without a reminder before deciding what to build next.
